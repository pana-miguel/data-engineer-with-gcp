# Data Engineer with GCP 🚀

Este repositorio recopilara la informacion sobre el uso de los servicios de gcp para la sertificacion como **Google Cloud Professional Data Engineer**.

## 📖 Introducción

La gran mayoria de este curso se utilizaran videos explicativos para poder interactuar con la plataforma de google cloud.
Este repositorio es una guía interactiva centrada en el ecosistema de **Google Cloud Platform (GCP)**. en los conocimientos para un data enginner utilizando cada uno de los servicios y explicando sus herramientas y usos en diferentes entornos.

> **Créditos y Referencia:**  
> Esta guía toma como base el curso de **Píldoras de Programación**, el cual puedes encontrar en el siguiente enlace: [Curso Píldoras de Programación](https://pildorasdeprogramacion.com/cursos/data-engineer-certification-gcp).

---
### 🎥 Metodología: Teoría y Práctica

este repositorio se divide en dos partes.

* **Documentación del Repositorio (Teoría y Fundamentos):** Es una guía teórica con algunas especificaciones y conceptos que debes tener en cuenta al trabajar con cada servicio.
* **Videos Explicativos y Prácticos:** En cada sección encontrarás enlaces a uno o más videos donde se hara uso práctico de los servicios de GCP. En ellos, tanto la práctica como los fundamentos se explican de forma directa y enfocada a la ejecución de los servicios.

## 🛠️ Servicios Principales de GCP (Guías y Recursos)

1. 🔐 [IAM Services](#) - Gestión de identidades, roles, permisos y políticas de seguridad.
2. 🗄️ [Cloud Storage](#) - Almacenamiento de objetos escalable a usos con big query o data lakes.
3. 🖥️ [Compute Engine](#) - Máquinas virtuales.
4. 📊 [BigQuery](#) - Data Warehouse empresarial para análisis masivo de datos mediante SQL.
5. ⚡ [Cloud Dataflow](#) - Procesamiento de datos en tiempo real (stream) y por lotes (batch) basado en Apache Beam.
